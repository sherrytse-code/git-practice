1. Git Flow

The standard collaborative loop: clone a repo, branch, commit locally, push, open a pull request, then merge.

  • git clone
  • git checkout -b newbranch
  • git add .
  • git commit -m "message"
  • git push
  • open a PR
  • merge PR & delete branch

3. Full Git Flow Example

Follow the GitGoing project from clone to cleanup. Commands from Section 2 appear here in context—refer back for individual command details.

  1. 1. Overview

    The full loop in three panels: clone and branch, commit and push, then sync and merge.

  2. 2. Clone and branch

    git clone https://github.com/LadyKerr/GitGoing.git
cd gitgoing
git checkout -b version1

    Download the repo, enter the project folder, and create a feature branch to work in safely.

  3. 3. Edit, stage, commit, and push

    code .
touch index.html script.js
git status
git add .
git commit -m "created initil project"
git push origin version1

    Make your changes, stage them, commit, and push the feature branch. See Basic Git Commands for git add, git commit, and git push screenshots.

  4. 4. Sync main after merge

    git switch main
git pull

    After your pull request is merged on GitHub, switch to main and pull so your local branch matches the remote. See the git pull screenshot in Basic Git Commands.

  5. 5. Merge updates into your feature branch

    git switch version1
git merge main

    Bring the latest main changes into your feature branch before continuing work.

  6. 6. Clean up branches

    git show
git branch -d update-name
git push --delete origin update-name

    Inspect the merged commit, then delete the feature branch locally and on GitHub. See the delete-branch and git show screenshots in Basic Git Commands.

  7. 7. Alternative: clone with GitHub Desktop

    Prefer a graphical interface? GitHub Desktop performs the same clone step without the terminal.

4. Link an Existing Local Project to GitHub

You already have a project folder on your computer and want to publish it on GitHub for the first time. This walkthrough uses the python-game example.

  1. 1. Create a new repository on GitHub

    • Click New repository
    • Give it a name
    • Choose Public or Private
    • Do not initialize it with a README if your local project already exists

  2. 2. Set up authentication

    Before your first push, generate a Personal Access Token. When Git prompts for a password, enter the token—not your GitHub login password.

    GitHub’s guide: Managing your personal access tokens

  3. 3. Initialize Git locally

    git init
touch README.md
git add .
git commit -m "initial commit"

    git init turns your folder into a Git repo. Stage and commit your existing project files.

  4. 4. Connect to the remote repository

    git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/REPO_NAME.git

    Rename your default branch to main and link your local repo to the empty GitHub repository you created in step 1.

  5. 5. Push to GitHub

    git push -u origin main

    Upload your commits and set main to track the remote branch.

  6. 6. Optional: upload via the web UI

    For small updates, you can add individual files on github.com instead of using the terminal.
