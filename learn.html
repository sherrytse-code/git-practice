1. The GitHub Flow

The standard loop: clone a repo, branch, commit locally, push, open a pull request, then merge.

  • git clone
  • git checkout -b newbranch
  • git add .
  • git commit -m "message"
  • git push
  • open a PR
  • merge PR & delete branch

2. Local Git basics

Initialize a repo, stage files, commit changes, and inspect history from the terminal.

3. Repositories & clone

4. Connect local project to GitHub

Link an existing folder on your machine to a remote repo and publish your work.

5. Sync with remote

6. Branches
